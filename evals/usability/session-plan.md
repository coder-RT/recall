# Session plan

## Before the participant arrives (20 minutes)

1. Scan the room with Recall and check that Found lists the three objects. Write down each object's measured position.
2. Place object A (keys) and object B (glasses) where the scan saw them. Leave object C (wallet) for task 3.
3. Mark a start spot about 3 m from the objects, facing away from them.
4. Clear the path (see `README.md`). Charge the phone. Put the Mac's API in `make live` and ask one test question.
5. Ask how they use their phone: VoiceOver on or off, speech rate, large text. Set the iPhone to match.

## Tasks

Alternate which object is searched by touch and which with Recall between participants (P1: A by touch, B with Recall;
P2: the reverse), so neither object is always the easy one.

For every task, record: **success** (yes / with help / no), **time**, **help given** (none / a spoken hint / guided
by hand), **wrong turns or errors**, and **what they said**.

### Task 1: by touch (baseline, at most 3 minutes)

"Your keys are somewhere in this room. Please find them however you normally would." Start the timer when they start
moving; stop it when they touch the object. Stop at 3 minutes if not found, and record "not found".

### Task 2: with Recall (at most 5 minutes)

"Now please use the app to find your glasses." Give no other instruction about how the app works. Time from the first
touch of the phone to touching the glasses. Note: did they hear "Looking for your glasses." straight away? Did they
use Take me there? Did the arrival check confirm? How many times did they ask again?

### Task 3: something moved

While they rest, move the wallet about 1 m from where it was scanned (note where). "Please use the app to find your
wallet." Recall knows the old place. Observe: does the arrival check say it's not there or found nearby, and can they
recover from that? This is the honest case: memory is only as fresh as the last scan.

### Task 4: delete a scan

"There's an old scan you don't want any more. Please delete it." (Prepare a spare scan beforehand.) Observe whether
the question about the Mac is clear, and whether they know what was deleted.

### Task 5: privacy

"Where does your information go when you use the app? Please find out." Afterwards ask them to say in their own words
what leaves the Mac. Record whether it matches the privacy note (photos to Meta's SAM 3.1, voice to Muse Voice
Transcribe, questions to Muse Spark Open).

## While moderating

- Say: "What are you thinking?", "What did you expect to happen?", "What would you do now?"
- Don't say how to do a task, don't point, and don't name buttons. If they're stuck for 60 seconds, give one spoken
  hint and record it as help.
- Stop at once if anything is unsafe, or if they're uncomfortable.

## After the tasks

Read the questions in `questionnaire.md`. Thank them. Within an hour, fill in `results-template.md` while you still
remember the details.
